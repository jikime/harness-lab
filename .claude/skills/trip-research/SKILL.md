# Trip Research

## 역할

가족 여행 준비 하네스의 첫 실행 단계 매뉴얼이다. 목적지·날짜·가족 구성이 확정된 뒤, 그 조건에 맞는 정보와 예약 후보를 모아 다음 단계(itinerary-planner)가 바로 쓸 수 있는 형태로 정리한다.

## 사용 조건

- 사용해야 하는 경우: `family-trip-prep-orchestrator`가 조사 단계를 위임했을 때, 또는 사용자가 "항공권 후보만 다시 찾아줘", "날씨 정보 업데이트해줘"처럼 조사 범위의 부분 재실행을 요청했을 때.
- 사용하지 말아야 하는 경우: 이미 확정된 조사 노트를 바탕으로 일정을 짜는 작업(itinerary-planning의 책임), 실제 항공권·숙소 예약·결제.

## 입력

- `artifacts/family-trip-prep/00-trip-brief.md`: 목적지, 날짜, 가족 구성, 예산, 제약.
- 부분 재실행이면 기존 `artifacts/family-trip-prep/01-research-notes.md`도 먼저 읽고 바뀐 부분만 갱신한다.

## 절차

1. `00-trip-brief.md`에서 목적지, 날짜, 가족 인원·나이, 예산 범위를 확인한다. 핵심 정보가 비어 있으면 조사를 진행하지 않고 오케스트레이터에게 차단을 보고한다.
2. 목적지 개요, 날씨/시즌 팁, 이동수단을 조사한다.
3. 가족 구성(특히 아이 나이)에 맞는 추천 명소·액티비티를 조사한다.
4. 항공권 후보 2-3개, 숙소 후보 2-3개를 가격대·조건 차이가 드러나게 조사한다. 출처(링크)와 조사 시점을 함께 남긴다.
5. 확인하지 못했거나 변동 가능성이 큰 정보는 "확인 필요"로 표시한다.

## 출력

- 저장 위치: `artifacts/family-trip-prep/01-research-notes.md`
- 필수 섹션: 목적지 개요 / 날씨·시즌 팁 / 가족 추천 명소·액티비티 / 이동수단 / 항공권 후보(가격·조건·링크) / 숙소 후보(가격·조건·가족친화 여부·링크) / 확인 필요 사항
- 완료 기준: 항공권·숙소 후보가 각 2개 이상이고, 모든 가격·조건에 출처가 있다.

## 품질 기준

- 통과 기준: 가족 구성(나이)에 맞지 않는 명소·숙소를 추천하지 않았는가, 가격에 출처와 조사 시점이 있는가.
- 사람 승인 조건: 없음(조사 단계는 정보 제공만, 승인 게이트는 dashboard 단계에서 표시).
- 실패 시 처리: 목적지·날짜·예산 중 하나라도 확정되지 않았으면 조사를 임의로 진행하지 않고 오케스트레이터에게 필요한 질문 목록을 넘긴다.

## 예시

Should trigger:
- "제주도 3박4일 가족여행 조사해줘"
- "숙소 후보만 다시 찾아줘"

Should not trigger:
- "이 항공권 지금 바로 예약해줘" (예약은 하네스가 실행하지 않음, 사람이 직접 진행)
- "지난 여행 일정표 다시 짜줘" (itinerary-planning의 책임)

Ask before proceeding:
- "가족 여행 준비해줘" (목적지·날짜·가족 구성이 없는 요청)
