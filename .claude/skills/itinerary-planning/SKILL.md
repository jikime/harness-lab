# Itinerary Planning

## 역할

가족 여행 준비 하네스의 두 번째 실행 단계 매뉴얼이다. 조사 노트와 가족 제약을 절충해, 검토자가 검증할 수 있는 형태의 일정·예산 초안을 만든다.

## 사용 조건

- 사용해야 하는 경우: `family-trip-prep-orchestrator`가 일정 설계 단계를 위임했을 때, `checklist-reviewer`가 이슈를 발견해 수정을 요청했을 때, 사용자가 "일정 다시 짜줘", "예산만 다시 배분해줘"처럼 부분 재실행을 요청했을 때.
- 사용하지 말아야 하는 경우: 목적지 정보를 새로 조사하는 작업(trip-research의 책임), 체크리스트 작성이나 초안 검토(trip-checklist-review의 책임).

## 입력

- `artifacts/family-trip-prep/00-trip-brief.md`
- `artifacts/family-trip-prep/01-research-notes.md`
- 수정 요청인 경우 `artifacts/family-trip-prep/03-checklist-review.md`의 이슈 목록

## 절차

1. 가족 구성(인원, 나이)과 예산 상한을 확인한다.
2. 조사 노트에서 가족 조건에 맞는 항목만 선별한다.
3. 하루 이동 거리와 활동 강도를 아이 나이·체력 기준으로 조정한다.
4. 예산 항목(항공/숙소/식비/액티비티/이동/예비비)별 금액을 배정하고, 항목을 손으로 다시 더해 합계와 일치하는지 검산한다.
5. 예산 초과나 일정 과밀처럼 절충이 필요했던 지점을 별도 섹션으로 명시한다.
6. 수정 요청을 반영하는 경우, 이슈별로 무엇을 바꿨는지 짧게 남긴다.

## 출력

- 저장 위치: `artifacts/family-trip-prep/02-itinerary-draft.md`
- 필수 섹션: 일자별 일정(시간대·장소·이동수단·소요시간) / 예산 내역표(항목별 금액 + 합계) / 절충한 트레이드오프와 이유 / 확인 필요 사항
- 완료 기준: 예산 내역표의 항목 합산과 표시된 합계가 정확히 일치한다.

## 품질 기준

- 통과 기준: 예산 합계 일치, 하루 이동시간이 가족 체력 기준을 넘지 않음, 트레이드오프가 숨겨지지 않고 명시됨.
- 사람 승인 조건: 없음(승인 게이트는 dashboard 단계에서 표시).
- 실패 시 처리: `checklist-reviewer`의 수정 요청은 최대 2회까지 반영한다. 2회 후에도 해결되지 않으면 오케스트레이터에게 보고하고 사람 확인을 요청한다.

## 예시

Should trigger:
- "조사 끝났으니 일정표 만들어줘"
- "예산 초과됐다는데 다시 배분해줘"

Should not trigger:
- "제주도 맛집 새로 조사해줘" (trip-research의 책임)
- "이 일정표 문제 없는지 검토해줘" (trip-checklist-review의 책임)

Ask before proceeding:
- 조사 노트가 없는 상태에서 일정표부터 만들어 달라는 요청
