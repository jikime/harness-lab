# Trip Checklist Review

## 역할

가족 여행 준비 하네스의 세 번째 실행 단계 매뉴얼이다. 일정표를 만든 역할과 분리된 검토자로서, 준비물 체크리스트를 만들고 예산·동선을 증거 기반으로 검증한다. 자기 자신이 만든 결과가 아니라 다른 역할(itinerary-planner)의 결과물을 회의적으로 본다.

## 사용 조건

- 사용해야 하는 경우: `family-trip-prep-orchestrator`가 검토 단계를 위임했을 때, 사용자가 "준비물 체크리스트만 다시 만들어줘", "일정표 숫자 다시 검토해줘"처럼 부분 재실행을 요청했을 때.
- 사용하지 말아야 하는 경우: 일정표를 새로 설계하는 작업(itinerary-planning의 책임), 목적지 조사(trip-research의 책임).

## 입력

- `artifacts/family-trip-prep/00-trip-brief.md`
- `artifacts/family-trip-prep/01-research-notes.md`
- `artifacts/family-trip-prep/02-itinerary-current.md`

## 절차

1. `02-itinerary-current.md`의 예산 내역표를 항목별로 직접 다시 더해 표시된 합계와 대조한다.
2. 일자별 일정의 이동 시간과 활동 강도를 가족 구성(나이·체력)과 대조한다.
3. 조사 노트에 없던 근거 없는 가정이 일정표에 들어갔는지 확인한다.
4. 여행 유형(국내/해외, 아이 동반 여부)에 맞는 준비물·서류 체크리스트를 작성한다(항목/담당자/기한/완료여부).
5. 이슈를 심각도(경미/중요/치명)와 함께 목록화한다. 중요 이상이면 itinerary-planner에게 수정을 요청한다.

## 판정 기준

- 통과 예: "예산 내역표 항목 합산이 표시된 합계와 정확히 일치한다", "하루 이동시간이 대중교통 기준 2시간 이내다".
- 탈락 예: "표시된 합계 210만원과 항목 합산 230만원이 다르다", "도착 3시간 안에 도보 이동 명소 2곳을 배치해 무리하다".
- 애매하면 통과시키지 않는다. "확인 필요"로 표시하고 이슈 목록에 남긴다.
- 판정 근거는 해당 줄/숫자를 직접 인용한다. "괜찮아 보인다" 같은 인상 평가를 쓰지 않는다.

## 출력

- 저장 위치: `artifacts/family-trip-prep/03-checklist-review.md`
- 필수 섹션: 준비물·서류 체크리스트 / 예산 재검산 결과(일치 여부와 차액) / 일정 동선 검토 / 발견한 이슈 목록(심각도) / 승인 필요 여부
- 완료 기준: 예산 재검산 결과가 명시적으로 일치/불일치로 판정되어 있다.

## 품질 기준

- 통과 기준: 모든 숫자·동선 판정에 근거(인용)가 있고, 치명 이슈가 없으면 "승인 필요 없음"으로 명시한다.
- 사람 승인 조건: 치명 이슈가 2회 수정 요청 후에도 남아 있으면 사람 확인 필요로 표시한다.
- 실패 시 처리: `02-itinerary-current.md`가 없으면 검토를 시작하지 않고 오케스트레이터에게 보고한다.

## 예시

Should trigger:
- "일정표 나왔으니 검토해줘"
- "체크리스트만 다시 만들어줘"

Should not trigger:
- "일정 자체를 다시 짜줘" (itinerary-planning의 책임)
- "숙소 후보 새로 찾아줘" (trip-research의 책임)

Ask before proceeding:
- `02-itinerary-current.md`가 아직 없는 상태에서 검토부터 요청하는 경우
