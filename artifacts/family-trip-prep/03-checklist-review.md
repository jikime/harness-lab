### 1-1. 2-3-2(식비 전체) 재검산

원문(416~424행) 4개 행을 직접 재합산:

```

카페·간식                 300,000  → 누계 2,625,000

```

표시된 소계 **2,905,000원**과 **정확히 일치**. v5 소계(2,950,000, v5 검토에서 직접 재검산해 확인함) 대비 차액: 2,950,000 − 2,905,000 = **45,000원**, 버퍼 감액분(325,000 − 280,000 = 45,000)과 **정확히 일치**.

### 1-2. 2-3-1(유명 맛집 8회) 무변경 재확인


= **1,785,000원**, 표시 소계와 일치. v5와 원 단위까지 동일 — v6이 이 표를 건드리지 않았다는 주장과 사실이 일치.

표시된 잔여 예산 상한 **9,720,000원**과 **정확히 일치**. 식비·쇼핑 두 줄 외 8개 항목(새해 전야·액티비티·공항·시내·브로드웨이·보험·예비비·미배분)은 v5 검토에서 재검산해 남긴 값과 **원 단위까지 완전히 동일**함을 대조 확인 — "이 두 줄만 ∓45,000원 상계 변경, 총액 불변"이라는 주장이 사실과 일치.

### 1-4. 2-1(총 예산) 재검산

```
항공 2,800,000 + 숙소 2,480,000 + 잔여배분 9,720,000
= 2,800,000+2,480,000=5,280,000 → +9,720,000=15,000,000
```
**15,000,000원 = 총 예산 상한, 초과 0원.** 2-1 표는 항공·숙소·잔여배분 세 줄 모두 v5와 원 단위까지 동일 — "2-1 표는 한 줄도 바뀌지 않았다"는 주장이 사실과 일치.

### 1-5. 상계(−45,000/+45,000) 검증

- 2-3-2 버퍼: 325,000 → 280,000 (**−45,000**)
- 2-2 식비: 2,950,000 → 2,905,000 (**−45,000**, 버퍼 감액이 그대로 반영)
- 2-2 쇼핑: 650,000 → 695,000 (**+45,000**)
- 2-2 총계에 대한 순효과: −45,000 + 45,000 = **0**

2-2 표에서 쇼핑 행 이후 누계(695,000 반영 후 7,370,000)를 v5 값(650,000 반영 후 7,370,000, 12-2 (4) 원문)과 대조하면 **동일한 7,370,000**으로 다시 만나며, 이후 보험·예비비·미배분까지 누계가 v5와 완전히 같은 경로로 9,720,000에 도달함을 확인함. **상계가 산술적으로 정확히 0임을 재확인.**

### 1-6. 그 외 소계(2-4·2-5·2-6) 무변경 확인

- 2-4 액티비티(천원): 120+80+100+90+120+120+140+400+130+180+270 = **1,750** ✔ (v5와 동일)

## 4. 스코프 4 — 13장 "v6 수정 이력" 자체 검증

13-2에 적힌 세 블록을 독립적으로 재현함(이미 1장에서 수행한 재계산과 별개로, 문서가 스스로 제시한 산식·역순 검산까지 재확인).

**(1) 2-3-2 식비 전체**: 정순 1,785,000+540,000+300,000+280,000=2,905,000. 역순(문서 989~995행) 280,000+300,000=580,000 → +540,000=1,120,000 → +1,785,000=2,905,000. **정순·역순 재현 결과 일치.** "v5 대비 45,000원 감소" 서술도 2,950,000−2,905,000=45,000으로 정확.

**(2) 2-2 잔여 예산 배분**: 정순(998~1010행) 2,905,000→3,805,000→5,555,000→5,875,000→6,355,000→6,675,000→7,370,000→7,470,000→9,370,000→9,720,000. 역순(1011행) 350,000+1,900,000=2,250,000 → +100,000=2,350,000 → +695,000=3,045,000 → +320,000=3,365,000 → +480,000=3,845,000 → +320,000=4,165,000 → +1,750,000=5,915,000 → +900,000=6,815,000 → +2,905,000=9,720,000. **정순·역순 모두 직접 재현해 일치 확인.**

**(3) 2-1 총 예산**: 2,800,000+2,480,000+9,720,000=15,000,000. **일치.**

**(4) 변경되지 않은 소계 재확인 블록(1023~1028행)**: 2-3-1(115+450+430+120+80+60+400+130=1,785 천원), 2-4(1,750천원), 2-5(320,000), 2-6(480,000), 예비비+미배분(2,250,000=23.15%) — 전부 직접 재계산해 표시값과 일치함을 확인.

**판정: 스코프 4 통과. 13장이 자체적으로 제시한 재검산은 과장·누락 없이 정확하다.**

## 5. "재검토 요청 최대 2회" 카운트에 대한 의견

itinerary-planner(오케스트레이터 경유)는 v6이 "checklist-reviewer 수정 요청에 대한 재수정"이 아니라 "사용자 확정 변경(브리프 갱신) 반영"이므로 v4에서 이미 사용한 "최대 2회" 카운트와 별개 건이라고 주장함. **이 판단에 동의함.**

- v6 변경의 원인은 `00-trip-brief.md`의 "v5 잔여 결정사항 확정(2026-07-29)" 섹션(59~62행)이며, 실제로 브리프를 직접 읽어 대조한 결과 "**45,000원 재배분처**: ... 사용자가 **쇼핑 예산으로 복원(650,000→695,000)**을 선택 — 식비 버퍼는 원래 값(280,000)으로 되돌림 ..."이라는 문장이 정확히 존재함을 확인함. planner가 임의로 재작업을 요청한 것이 아니라, v5 검토가 "확인 필요"로 열어 두었던 R2(45,000원 배분처)가 사용자에 의해 이제 닫힌 것임.
- 이는 v3→v4의 카운트(checklist-reviewer 이슈 지적 → 재수정)와 성격이 다르며, v6에서도 새로운 중요·치명 이슈가 발견되지 않았으므로 이번 라운드에서 "1회 사용"이 발생하지도 않았음.
- 다만 앞선 v5 검토와 동일한 원칙을 유지함: 만약 이번에 중요·치명 이슈가 발견되어 수정을 요청했다면 그것은 "v6 건에 대한 새로운 1회차"로 셌을 것이며, v6도 무제한 반복까지 허용하는 것은 아님.
