## 2. 예산 재검산 결과

### 2-1. 전체 예산 재검산 (총 예산 15,000,000원)

- 항공 2,800,000 + 숙소 2,480,000 = 5,280,000
- 5,280,000 + 잔여 9,720,000 = **15,000,000**
- 문서 표시(2-1, "손 검산" 줄 246): "2,800,000 + 2,480,000 = 5,280,000 → 5,280,000 + 9,720,000 = 15,000,000 ✔" → **직접 재계산 결과와 일치**

### 2-2. 잔여 예산 9,720,000원 배분표 재검산 (요청받은 항목 1)

직접 재합산: 2,900,000 + 900,000 + 1,750,000 + 320,000 + 480,000 + 320,000 + 700,000 + 100,000 + 1,900,000 + 350,000

```
2,900,000
+  900,000 = 3,800,000
+1,750,000 = 5,550,000
+  320,000 = 5,870,000
+  480,000 = 6,350,000
+  320,000 = 6,670,000
+  700,000 = 7,370,000
+  100,000 = 7,470,000
+1,900,000 = 9,370,000
+  350,000 = 9,720,000
```

→ **재계산 결과 9,720,000원, 문서 표시 합계(9,720,000원)와 정확히 일치. 전체 총액(2,800,000+2,480,000+9,720,000=15,000,000원)과도 일치. 통과.**

### 2-3. 하위 소계 재검산

- 식비(2-3): 400,000+630,000+770,000+400,000+400,000+300,000 = **2,900,000** → 문서 표시(2,900,000)와 일치
  - 이 중 "저녁 — 캐주얼 7회"와 "저녁 — 특별 디너 1회"의 날짜 배정은 아래 2-4에서 별도 검증
- 액티비티(2-4): 120,000+80,000+100,000+90,000+120,000+120,000+140,000+400,000+130,000+180,000+270,000 = **1,750,000** → 일치
- 공항+짐보관(2-5): 150,000+150,000+20,000 = **320,000** → 일치
- 시내이동(2-6): 190,000+290,000 = **480,000** → 일치

**결론: 예산표의 산술은 총액·중간 소계·최하위 세부까지 모든 단계에서 표시 값과 정확히 일치합니다. v1이 지적한 예산 관련 이슈(#1, #4, #6)는 구조적으로 해소되었습니다.**

### 3-4. 신규 발견 사항 — Day6 소호 쇼핑 슬롯 시간 초과 (경미)

- 줄 153: "11:00~13:30 | 소호(SoHo) 편집숍·브랜드 거리 쇼핑 | 도보8분(Astor Place) + 6호선 Astor Place→Spring St 6분 | 이동 약16분 + 쇼핑 2시간30분"
- 슬롯 시간: 13:30-11:00 = **150분**
- 서술된 내용 합계: 이동 16분 + 쇼핑 150분 = **166분**
- 슬롯(150분)보다 서술된 활동 합계(166분)가 **16분 초과**합니다. 다른 모든 행은 이동시간을 별도 행으로 분리하거나 슬롯 안에 여유를 두는 방식인데, 이 행만 이동시간과 활동시간을 합산해 슬롯 폭을 넘습니다.
- 실질적 영향은 작습니다(16분 오차, 무리한 이동으로 보긴 어려움)만, 명백한 문서 내 산술 불일치이므로 이슈로 기록합니다.

### 4-1. Trattoria Dell'Arte 조망석 리스크

### 4-2. QC NY Spa 페리 운항 스케줄 미확인

- itinerary-planner 주장(줄 445): "QC NY Spa의 12/31 겨울 페리 운항 시각이 확인되지 않아 이 배치가 실제로 성립하는지는 미확정입니다."

- 다만 문서는 대체 플랜을 이미 명시했습니다(줄 187): "스파를 12/30 오전으로 이동하고 12/31 낮은 숙소 도보권 저강도 일정으로 대체". 6장 리스크표에도 별도 행으로 등재되어 있습니다.
- 판정: **리스크 인정 타당, 심각도 중요.** 대체 플랜이 구체적으로 존재하므로 **치명은 아니며**, 예약 단계 확인 사항으로 분류합니다.
